# LEICA BRASS MASTER 📷
> Professional Exposure & DoF Calculation System for Analog Photographers

**LEICA BRASS MASTER** は、クラシックカメラ（特にライカなどのレンジファインダー機やオールドレンズ）の撮影を強力にサポートするために開発された、真鍮調のメカニカルなUIを持つ露出計＆被写界深度（DoF）算出Flutterアプリケーションです。

## ✨ 主な機能
* **クラシック・スプラッシュ & ギミックアニメーション** (起動ロゴ・絞り羽開眼・メーター針躍動)
* **ダブルダイアル露出計算機** (ISO, Av, Tv, EV直感操作)
* **フィルム・プリセット & 相反不軌補正** (Kodak, Fuji, Ilford等の自動長秒補正)
* **被写界深度（DoF）＆ ゾーンフォーカス表示**
* **AR擬似レンジファインダー**

## 🚀 実行方法
```bash
flutter pub get
flutter run
```
